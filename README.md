# LLMs vs BERT vs BiLSTM

This repository contains Python scripts for evaluating different prompt variants in sentiment classification using local language models (`ollama`) and cloud-based OpenAI models. The prompt logic has been refactored into a centralized module at `src/constants/prompts.py`.

## Project Structure

- `run-llama-local.py` - runs local inference using the `llama3.1:8b` model via `ollama`.
- `run-gpt-cloud.py` - runs inference via OpenAI chat completions.
- `src/constants/prompts.py` - centralized file containing prompt templates used by both scripts.
- `ollama_artifacts/` - output directory generated by the local script, including CSV metrics and plots.
- `venv/` - Python virtual environment (not committed to source control, present locally).

## Requirements

- Python 3.9+ recommended
- `ollama` installed and configured to run `llama3.1:8b` locally
- OpenAI account and `OPENAI_API_KEY` environment variable set to run `run-gpt-cloud.py`

Python dependencies used:

- openai
- ollama
- datasets
- pandas
- numpy
- scikit-learn
- tqdm
- matplotlib
- seaborn

## Setup

1. Create and activate a virtual environment:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install openai ollama datasets pandas numpy scikit-learn tqdm matplotlib seaborn
```

3. Set the OpenAI API key (for `run-gpt-cloud.py`):

```powershell
$env:OPENAI_API_KEY = "your_api_key_here"
```

## Usage

### Run local inference with Ollama

```powershell
python run-llama-local.py
```

Artifacts will be saved to `ollama_artifacts/`, including `ollama_metrics_summary.csv`, ROC curves, and confusion matrices.

### Run cloud inference with OpenAI

```powershell
python run-gpt-cloud.py
```

## Notes

- `run-gpt-cloud.py` imports prompt templates from `src/constants/prompts.py`.
- If package import issues occur, run scripts from the repository root or set `PYTHONPATH` to include the project root.

## Prompts

All prompts are centralized in `src/constants/prompts.py`, making it easier to maintain and experiment with Zero-Shot, Few-Shot, and Chain-of-Thought variants.
